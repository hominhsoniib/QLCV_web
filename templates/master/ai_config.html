3 BƯỚC TẠO CLOUDFLARE WORKER MIỄN PHÍ ĐỂ VƯỢT CHẶN VPS:
  1. Đăng nhập dash.cloudflare.com (tạo tài khoản miễn phí).
  2. Vào mục Compute (Workers) → Workers & Pages → Bấm Create Application → Create Worker → Bấm Deploy.
  3. Bấm Edit code, xoá toàn bộ code cũ và dán đoạn mã JavaScript bên dưới → Bấm Deploy:
export default {
  async fetch(request) {
    const url = new URL(request.url);
    url.hostname = 'generativelanguage.googleapis.com';
    const newHeaders = new Headers(request.headers);
    newHeaders.delete('host');
    const newRequest = new Request(url.toString(), {
      method: request.method,
      headers: newHeaders,
      body: request.body,
      redirect: 'follow'
    });
    return fetch(newRequest);
  }
};
